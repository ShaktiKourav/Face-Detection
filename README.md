## 🎯 What is AI MoodSense?

**AI MoodSense** is a full-stack AI-powered face detection and emotion recognition system.

The application captures a user's face through the webcam and processes the image using an AI pipeline to determine the user's emotional state.

The detected emotion is then used to:

- 🧠 Analyze facial emotion
- 📊 Calculate confidence score
- 🎭 Detect current mood
- 🖼️ Upload captured image securely
- ☁️ Store image on ImageKit
- 🗄️ Store detection history in MongoDB
- 🎵 Recommend music according to mood
- 📈 Display detection statistics
- 🔐 Protect user data with authentication
